# Employee Management

This project is a Spring Boot application for managing employees and tasks. It includes RESTful web services to add and list tasks.

## Getting Started

These instructions will get you a copy of the project up and running on your local machine for development and testing purposes.

### Prerequisites

- Java 17
- Maven 3.6+
- Git
